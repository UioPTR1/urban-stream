
# Agent Instructions

This repository is a learning-oriented real-time data
engineering project.

## Development rules
- Python 3.14
- Prefer simple, testable, maintainable code.
- Follow existing project conventions.
- Do not introduce dependencies without justification.
- Do not change architecture without discussing tradeoffs.
- Do not generate complete features unless explicitly requested.
- Prefer explanations, reviews, and small focused changes.
- Never delete data or run destructive commands without approval.
- Never commit credentials, secrets, or local environment files.

## Testing
- Use pytest.
- Add tests for new behavior when appropriate.
- Report test failures instead of hiding them.

## Learning
- The repository owner is learning Data Engineering.
- Explain unfamiliar infrastructure and streaming concepts.
- Preserve opportunities for the owner to implement core logic.
